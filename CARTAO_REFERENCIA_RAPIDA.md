## 🚀 Como Usar (Mobile)

1. Abra o PWA no celular
2. Entre na ordem de serviço
3. Toque "Atualizar Status"
4. Selecione "Pronto para Retirada"
5. Toque "Atualizar Status"
6. **WhatsApp abre automaticamente!**

---

## 💻 Como Usar (Desktop)

1. Abra o sistema no computador
2. Entre na ordem de serviço
3. Clique "Atualizar Status"
4. Selecione "Pronto para Retirada"
5. Clique "Atualizar Status"
6. **WhatsApp abre em nova aba!**

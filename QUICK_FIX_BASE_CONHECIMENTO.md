## 🔧 COMO USAR

### Acessar
```
Admin → Base de Conhecimento (menu lateral)
```

### Ver Casos
```
1. Clique na aba "Biblioteca"
2. Veja 28+ casos disponíveis
3. Use busca ou filtros
4. Clique em 👁️ para detalhes
```

### Adicionar Mais
```
1. Clique na aba "Adicionar Caso"
2. Preencha formulário
3. Salve
```

### Extrair Mais de OS's
Execute no SQL (opcional):
```sql
SELECT extract_cases_from_service_orders();
```

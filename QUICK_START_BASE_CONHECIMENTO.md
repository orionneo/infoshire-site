## 🎯 ACESSO RÁPIDO

### Pelo Menu
```
Admin → Base de Conhecimento (6º item)
Ícone: 🧠 (Brain)
```

### URL Direta
```
/admin/ai-knowledge
```

## 📋 3 ABAS DISPONÍVEIS

### 1️⃣ ADICIONAR CASO
**Use quando:** Acabou de resolver um caso e quer documentar

**Campos obrigatórios:**
- ✅ Título
- ✅ Tipo de equipamento
- ✅ Descrição do problema
- ✅ Descrição da solução

**Campos opcionais:**
- Marca, Modelo
- Dificuldade (Fácil/Médio/Difícil)
- Tempo estimado
- Peças usadas
- Custo
- Tags
- Notas

### 2️⃣ BIBLIOTECA
**Use quando:** Quer consultar ou gerenciar casos existentes

**Recursos:**
- 🔍 Busca por texto
- 🎯 Filtros (equipamento, dificuldade)
- 👁️ Visualizar detalhes
- ✏️ Editar caso
- 🗑️ Deletar caso
- 👍 Marcar como útil

### 3️⃣ ESTATÍSTICAS
**Use quando:** Quer ver métricas e configurar IA

**Mostra:**
- Total de casos documentados
- Visualizações e avaliações
- Top contribuidores
- Métricas do motor de IA
- Configurações do sistema

---

## 💡 EXEMPLO PRÁTICO

### Documentar um caso:

1. **Acesse:** Admin → Base de Conhecimento
2. **Aba:** Adicionar Caso (já é a padrão)
3. **Preencha:**
   ```
   Título: Notebook Dell não liga após queda
   Equipamento: Notebook
   Marca: Dell
   Modelo: Inspiron 15 3000
   Problema: Cliente derrubou notebook, não liga mais, 
             LED power pisca 3 vezes
   Solução: Verificado RAM desencaixada. 
            Reencaixe dos módulos resolveu
   Dificuldade: Fácil
   Tempo: 15 minutos
   Tags: ram, não liga, queda
   ```
4. **Clique:** Salvar Caso
5. **Pronto!** ✅

### Consultar casos:

1. **Acesse:** Admin → Base de Conhecimento
2. **Aba:** Biblioteca
3. **Busque:** "não liga"
4. **Filtre:** Equipamento = Notebook
5. **Clique:** 👁️ no caso desejado
6. **Veja:** Todos os detalhes
7. **Marque:** 👍 se foi útil

## Primeiro Acesso

### Método 1: Criar Admin Padrão
1. Acesse `/init-admin`
2. Clique em "Criar Administrador Padrão"
3. Login com `admin` / `admin123`

### Método 2: Primeiro Registro
1. Acesse `/register`
2. Crie sua conta
3. Primeiro usuário = admin automático

## Gerenciar Usuários

1. Acesse `/admin/users`
2. Veja lista de todos os usuários
3. Altere role: Cliente ↔ Administrador
4. Mudanças aplicadas instantaneamente

### Admin (admin)

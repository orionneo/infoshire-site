# 📋 Menu Administrativo - InfoShire

## Menu da Área Administrativa

O painel administrativo da InfoShire possui o seguinte menu de navegação:

### 🔧 Itens do Menu

1. **📊 Dashboard**
   - Rota: `/admin`
   - Ícone: LayoutDashboard
   - Descrição: Visão geral com métricas e estatísticas

2. **📦 Ordens de Serviço**
   - Rota: `/admin/orders`
   - Ícone: Package
   - Descrição: Gerenciamento completo de ordens de serviço

3. **👥 Clientes**
   - Rota: `/admin/clients`
   - Ícone: Users
   - Descrição: Visualização e gerenciamento de clientes

4. **👤 Usuários**
   - Rota: `/admin/users`
   - Ícone: UserCog
   - Descrição: Gerenciamento de usuários e permissões

5. **⚙️ Configurações** ✨
   - Rota: `/admin/settings`
   - Ícone: Settings
   - Descrição: Personalização do conteúdo do site público

---

## ⚙️ Página de Configurações

A página de **Configurações** (`/admin/settings`) permite personalizar:

### Informações Gerais
- Nome do site
- Logotipo (futuro)

### Página Inicial
- Título principal do hero
- Subtítulo do hero

### Página Sobre
- Conteúdo completo da página sobre a empresa

### Informações de Contato
- E-mail de contato
- Telefone
- Endereço completo

---

## 🎨 Localização do Menu

### Desktop (≥1024px)
- Sidebar fixa à esquerda
- Sempre visível
- 256px de largura

### Mobile (<1024px)
- Menu hambúrguer no topo
- Sheet lateral que abre ao clicar
- Mesmo conteúdo do desktop

## 🚀 Como Acessar

1. Faça login como administrador
2. Você será redirecionado para `/admin`
3. No menu lateral, clique em **"Configurações"**
4. Ou acesse diretamente: `/admin/settings`

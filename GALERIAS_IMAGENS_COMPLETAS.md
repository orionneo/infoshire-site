## 🎨 Padrão de Galeria Implementado

### Estrutura HTML/JSX

```tsx
{/* Image Gallery Section */}
<div className="mt-16">
  <h2 className="text-3xl font-bold text-center mb-8">
    [Título] <span className="text-primary">[Destaque]</span>
  </h2>
  <div className="grid grid-cols-1 md:grid-cols-2 gap-6">
    {/* Image Card */}
    <div className="relative group overflow-hidden rounded-lg border border-border hover:border-primary transition-all duration-300">
      <img
        src="[IMAGE_URL]"
        alt="[DESCRIPTION]"
        className="w-full h-64 object-cover transition-transform duration-500 group-hover:scale-110"
      />
      <div className="absolute inset-0 bg-gradient-to-t from-black via-black/50 to-transparent opacity-0 group-hover:opacity-100 transition-opacity duration-300">
        <div className="absolute bottom-0 left-0 right-0 p-6">
          <h3 className="text-xl font-bold text-white mb-2">[TÍTULO]</h3>
          <p className="text-gray-300 text-sm">[DESCRIÇÃO]</p>
        </div>
      </div>
    </div>
  </div>
</div>
```

### Características Visuais

#### Container
- Margin top: `mt-16` (64px)
- Título: `text-3xl font-bold text-center mb-8`
- Palavra destacada: `text-primary`
- Grid: `grid-cols-1 md:grid-cols-2 gap-6`

#### Image Card
- Container: `relative group overflow-hidden rounded-lg`
- Border: `border-border hover:border-primary`
- Transição: `transition-all duration-300`

#### Imagem
- Dimensões: `w-full h-64`
- Object fit: `object-cover`
- Hover: `group-hover:scale-110`
- Transição: `transition-transform duration-500`

#### Overlay (Hover)
- Posição: `absolute inset-0`
- Gradient: `bg-gradient-to-t from-black via-black/50 to-transparent`
- Opacity: `opacity-0 group-hover:opacity-100`
- Transição: `transition-opacity duration-300`

#### Texto Overlay
- Container: `absolute bottom-0 left-0 right-0 p-6`
- Título: `text-xl font-bold text-white mb-2`
- Descrição: `text-gray-300 text-sm`

## 🎯 Efeitos Visuais Implementados

### 1. Hover na Imagem
```css
transition-transform duration-500
group-hover:scale-110
```
**Efeito**: Zoom suave de 110% ao passar o mouse

### 2. Border Hover
```css
border-border hover:border-primary
transition-all duration-300
```
**Efeito**: Border muda de cinza para verde neon

### 3. Overlay Gradient
```css
bg-gradient-to-t from-black via-black/50 to-transparent
opacity-0 group-hover:opacity-100
transition-opacity duration-300
```
**Efeito**: Gradient preto aparece suavemente com texto

### 4. Texto Overlay
```css
text-xl font-bold text-white
text-gray-300 text-sm
```
**Efeito**: Título branco + descrição cinza clara

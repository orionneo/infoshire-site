# 🚀 Busca Web com IA - Guia Rápido

## 📍 Onde Encontrar

### 1️⃣ Ao Criar Nova OS
**Admin > Ordens de Serviço > Criar Nova OS**
- Role até o final do formulário
- Card: "🔍 Buscar Informações Técnicas"
- Use para: Especificações de equipamentos, problemas comuns

### 2️⃣ Durante Diagnóstico
**Admin > Ordem de Serviço (detalhes) > Painel Lateral**
- No painel "Diagnóstico Assistido"
- Botão: "Buscar Mais Informações na Web"
- Use para: Causas, testes, soluções

### 3️⃣ Na Base de Conhecimento
**Admin > Base de Conhecimento IA > Documentar Novo Caso**
- Botão: "Validar com Web"
- Use para: Validar definições técnicas

## 💡 Exemplos de Busca

### Especificações
```
✅ iPhone 13 Pro Max bateria mAh
✅ Samsung Galaxy S21 tela AMOLED especificações
✅ MacBook Pro M1 2020 RAM máxima
```

### Problemas
```
✅ notebook não liga após queda d'água
✅ celular não carrega bateria incha
✅ tela preta mas aparelho liga som
```

### Termos Técnicos
```
✅ backlight LCD funcionamento
✅ reballing BGA processo
✅ PMIC chip função
```

## ⚡ Como Usar

1. **Digite** sua consulta
2. **Clique** em "Buscar"
3. **Aguarde** até 30 segundos
4. **Veja** resultados com fontes
5. **Clique** em "Aplicar" para usar

## ⚠️ Importante

- ⏱️ Primeira resposta pode levar até 30s
- 🔍 Sempre verifique as fontes citadas
- ✅ Valide informações antes de usar
- 👨‍🔧 Técnico tem controle final
- 💰 Totalmente gratuito!

## 🎯 Dicas

✅ **Seja específico**: "Samsung S21" > "celular"
✅ **Use modelo exato**: "iPhone 13 Pro Max" > "iPhone"
✅ **Combine problema + equipamento**: "MacBook Pro não liga"
❌ **Evite termos genéricos**: "problema" "defeito" "quebrado"
